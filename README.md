> 💡 **Optional:** Set up [GitHub Actions](#-click-to-activate-snake-animation-github-actions-setup) below to show **your own** contributions in the snake!

</div>

<details>
<summary><b>⚙️ Click to activate Snake Animation (GitHub Actions setup)</b></summary>

Create `.github/workflows/snake.yml` in your profile repo:

```yaml
name: Generate Snake Animation
on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>
